# HUT OS Organization

**Hamedan University of Technology Operating System**

Public open-source home of HUT OS — a minimal, educational Linux-based operating system.

## Repositories

| Repository | Purpose |
|------------|---------|
| [**hut-os**](https://github.com/hut-os/hut-os) | Main distribution: rootfs, init, build system, docs |
| [**linux-config**](https://github.com/hut-os/linux-config) | Kernel defconfig and build instructions for upstream Linux |

## About

HUT OS started as a personal project by [Arshia Mohammadei](https://github.com/itashia) while studying Mechanical Engineering at Hamedan University of Technology.

> One day in the dormitory study hall, with nothing better to do — build an OS. Name it after the university.
